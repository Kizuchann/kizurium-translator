# Third-party data / model license inventory

Machine-readable copy: `docs/licenses-inventory.toml`.

This inventory is the gate before bundling or downloading optional packs.
Rows marked `bundled = false` are **not** shipped in the wheel; the user
installs or imports them separately.

## Required checklist

| component | license (summary) | redistributable? | attribution? | commercial? | bundled? |
|-----------|-------------------|------------------|--------------|--------------|----------|
| JMdict / JMnedict | CC BY-SA (EDRDG) | yes, with share-alike | required | yes w/ attribution | no (optional later) |
| Tatoeba | CC BY 2.0 (sentences; check per-row) | yes with attribution | required | yes w/ attribution | no |
| OPUS-MT (Helsinki-NLP) | CC BY 4.0 (models; verify card) | usually yes | required | usually yes | no (optional) |
| RapidOCR / PaddleOCR assets | Apache-2.0 (engine); models vary | engine yes; models check | model-dependent | model-dependent | no (pip optional) |
| CTranslate2 | MIT | yes | courtesy | yes | no (optional) |
| pymorphy3 (+ dicts) | MIT (lib); dicts often LGPL/OpenCorpora | lib yes; dicts check | dict-dependent | dict-dependent | no (not yet a dep) |
| MeikiOCR assets | see package; model download on first use | package-dependent | package-dependent | package-dependent | no (pip optional) |

## Policy

- Do not vendor copyrighted game scripts or XUnity AutoGenerated dumps.
- Optional offline packs must carry `license`, `license_url`, `source_url`, and
  `sha256` in their manifest.

## NLLB is not default

NLLB (including `nllb-200-distilled-600M`) may be researched later for broad
multilingual coverage, but public model lines need a separate license review
(often CC-BY-NC or similar non-commercial terms).

For the first release:

- Default / catalog offline MT = pair-specific permissive models (OPUS-MT via
  CTranslate2: `opus-mt-en-ru`, `opus-mt-ja-ru`).
- NLLB is **not** bundled, **not** in `language_packs/catalog.toml`, and
  **not** selected by any default config.
- Enabling NLLB requires an explicit future legal decision + inventory update;
  until then the catalog gate rejects any `nllb*` pack id.

## Argos optional candidate

Argos Translate is documented in `docs/argos.md` and probed by
`translation/argos_probe.py`. It is **not** a core backend and must not be the
sole offline guarantee until `strict_offline_allowed=True` under a blocked
network.
