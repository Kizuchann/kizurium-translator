# External dictionary research / import

Source of truth for formats we may *read*. We do **not** ship copyrighted game
scripts or redistributed AutoGenerated dumps in the repository.

## XUnity AutoTranslator

- Upstream: https://github.com/bbepis/XUnity.AutoTranslator
- Per-language text dir: `Translation/{Lang}/Text/`
- Autogenerated cache (lowest priority): `_AutoGeneratedTranslations.txt`
- Manual overrides: any other `*.txt` (or zip) in that tree
- Substitutions (pre-translate): `_Substitutions.txt`
- Line formats:
  - exact: `Original=Translated`
  - regex: `r:pattern=replacement`
  - splitter regex: `sr:pattern=replacement`
- Scope: scene directives in `[brackets]` exist; we skip them on import
- Legal: plugin is redistributable; **game text inside dumps is still the
  game's copyright**. Import only files the user owns/has rights to use.
  Never vendor a full game script into `data/lexicons/`.

## TENUKI

- Per-game directories with plain-text dictionaries and regex dictionaries
- Practical interchange for us: `source=target` lines or TSV `source<TAB>target`
- Compiled indexes are implementation details; we import the text sources
- Same copyright rule as XUnity: user-supplied only

## RPG Maker ecosystem

- Common shapes: glossary CSV/TSV, project translation maps, TMX-like memories
- For the first release we accept TSV/`=` only; richer TMX belongs with a later
  translation-memory format

## Importer

```text
kizurium-translator --import-dictionary PATH [--pack-id ID] [--dict-format auto|xunity|plain]
```

The importer reads **one text file** per invocation. It does not unpack zip
archives; extract the `*.txt` files first and import the one you need.
`--dict-format auto` (the default) treats the file as XUnity when it contains an
`r:` or `sr:` line, otherwise as a plain `source=target` / TSV dictionary.

Writes:

```text
$XDG_DATA_HOME/kizurium-translator/dictionaries/<pack-id>/
  manifest.toml   # source_language = "auto", target_language = "ru",
                  # scope = "user", license = "user-provided"
  terms.tsv       # exact entries, when the file has any
  regex.tsv       # r:/sr: rules, only when the file has any
```

`--pack-id` defaults to a sanitized form of the file name. The manifest records
the import source in `import_note`; it does not guess a language pair.

Machine translation still never becomes an authoritative glossary entry.
